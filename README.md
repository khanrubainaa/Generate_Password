
# Password Generator & Strength Checker

A simple Python program to generate random passwords and check their strength.

## Features
- Generate random passwords.
- Include letters, numbers, and symbols.
- Check password strength.
- Display Weak, Medium, or Strong.

## Concepts Used
- random module
- string module
- Functions
- Loops
- If-else conditions

## How to Run
Run the following command in VS Code terminal:

python password_tool.py
