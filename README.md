
# Password Generator & Strength Checker

A Python command-line project that generates random passwords and checks password strength.

## Features

- Generate passwords of a user-defined length.
- Include uppercase letters, lowercase letters, digits, and symbols.
- Check password length.
- Check whether the password contains digits, uppercase letters, and symbols.
- Display password strength as Weak, Medium, or Strong.
- Menu-driven program.

## Python Concepts Used

- random module
- string module
- Functions
- while and for loops
- if-else conditions
- User input
- String methods
- any() and len()
- Exception handling

# How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
python password_tool.py
```
